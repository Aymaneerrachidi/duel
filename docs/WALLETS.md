# Connecting Phantom

Open [PNL DUELS](https://duel-rose.vercel.app) and refresh to load the latest version.

1. Select **Connect wallet → Solana wallet → Connect Phantom (Solana)** and approve the sign-in message.
2. Open the wallet menu again, select **EVM wallet → Link Phantom (EVM)**, and approve the second message.
3. Both addresses appear in the wallet menu under one trader account. Either linked wallet can sign back into that account.

On mobile, open the site inside Phantom's browser. On desktop, allow the Phantom extension on this site. If Phantom is missing from one tab, confirm that the corresponding wallet is enabled in Phantom and reload.

You do not need an API key, private key or secret recovery phrase for connecting Phantom. The signatures prove address ownership; they do not send transactions. EVM portfolio tracking covers the app's enabled networks without switching the wallet network.

If you change accounts or networks during a sign-in request, dismiss the old request and connect again. Each challenge belongs to the address and network selected when it was issued.
